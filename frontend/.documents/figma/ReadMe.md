# Installation of Figma File

1. Gå på "Drafts" i sidebaren i figma-teamet og trykk på `+`-tegnet
2. Velg "Import" og så dra inn `Bachelor2026-Bouvet_Event.fig`-filen eller velg "Import from computer" og finn den og trykk.
3. Vent til den er ferdig å importere filen (kan ta noen minutter)
4. Trykk "Done" og du er ferdig, eller "Move into Project"-og velg prosjektet du vil flytte den til.
